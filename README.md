
# StudyFlow

StudyFlow היא מערכת אינטרנטית לניהול לימודים, המיועדת לתלמידים שרוצים לארגן את המשימות, המבחנים, העבודות ומערכת השעות שלהם במקום אחד.

## מטרת הפרויקט

לאפשר לתלמידים לנהל את הלימודים בצורה נוחה ומסודרת, לעקוב אחר משימות ולתכנן את זמנם.

## טכנולוגיות

- C# ו-.NET 10
- ASP.NET Core Web API
- Blazor
- MySQL
- Bootstrap
- HTML ו-CSS

## מבנה הפרויקט

הפתרון מחולק לארבעה פרויקטים:

- **Model** – מחלקות המייצגות את הנתונים במערכת.
- **DAL** – גישה לבסיס הנתונים וביצוע שאילתות SQL.
- **StudyFlowAPI** – קבלת בקשות HTTP וביצוע פעולות באמצעות DAL.
- **View** – ממשק המשתמש שנבנה ב-Blazor.

## בסיס הנתונים

המערכת כוללת שמונה טבלאות:

1. Roles
2. Users
3. Subjects
4. UserSubjects
5. AcademicItems
6. TimetableEntries
7. StudyMaterials
8. StudySessions

טבלת Users מקושרת לטבלת Roles באמצעות RoleID.

## מה כבר מומש?

- יצירת בסיס הנתונים והטבלאות.
- פעולות API לניהול משתמשים.
- בדיקת התחברות.
- הרשמת משתמשים עם בדיקות תקינות.
- ממשק ראשי, מסך כניסה ומסך הרשמה.
- רכיבי תצוגה משותפים.
- הסתרת סיסמאות מתשובות ה-API.
- דפי בית נפרדים לפי תפקידי המשתמשים.
- בדיקת הרשאות בדפים מוגנים.
- עיצוב דפים פנימיים לתלמיד, למורה ולמנהל.
- ניווט בין דפי הבית לדפים הפנימיים.
- עיצוב רספונסיבי באמצעות Bootstrap.

## גרסאות אחרונות

### V7 – אבטחת סיסמאות

- שמירת סיסמאות באמצעות BCrypt.
- בדיקת סיסמאות מוצפנות בתהליך ההתחברות.
- מניעת החזרת סיסמאות בתשובות ה-API.

### V8 – הרשאות לפי תפקידים

- הגדרת שלושה תפקידים: Admin, Student ו-Teacher.
- יצירת משתמשי בדיקה לכל תפקיד.
- יצירת דף בית נפרד לכל תפקיד.
- הפניית המשתמש לדף המתאים לאחר ההתחברות.
- בדיקת הרשאות לפני הצגת דפים מוגנים.
- הפניית משתמשים ללא הרשאה לדף "אין הרשאה".
- הפניית אורחים לדף ההתחברות.

### V9 – עיצוב הדפים הפנימיים

- עיצוב דפי הבית של Student, Teacher ו-Admin.
- יצירת רכיב משותף InfoCard להצגת כרטיסיות מידע.
- עיצוב שלושה דפים פנימיים לתלמיד:
  - משימות ומבחנים.
  - מערכת שעות.
  - חומרי לימוד.
- עיצוב שלושה דפים פנימיים למורה:
  - מקצועות לימוד.
  - משימות.
  - חומרי לימוד.
- עיצוב שלושה דפים פנימיים למנהל:
  - ניהול משתמשים.
  - תפקידים והרשאות.
  - ניהול מידע.
- הצגת כרטיסיות, טבלאות ואזורי מידע באמצעות Bootstrap.
- התאמת התצוגה למסכים בגדלים שונים.
- הוספת קישורים בין דפי הבית לדפים הפנימיים וכפתורי חזרה.
- שמירה על מנגנון ההתחברות וההרשאות הקיים מ-V8.
- שימוש בנתוני דוגמה קבועים לצורך עיצוב התצוגה.
- ללא שינויים בבסיס הנתונים, ב-DAL או ב-API.

## הפעלת הפרויקט

1. פותחים את הפתרון StudyFlow ב-Visual Studio.
2. מוודאים ששרת MySQL פועל.
3. מגדירים את מחרוזת החיבור לבסיס הנתונים ב-User Secrets של StudyFlowAPI.
4. מגדירים את כתובת ה-API ב-ApiBaseUrl של פרויקט View.
5. מגדירים את StudyFlowAPI ואת View כפרויקטי הפעלה.
6. מפעילים את המערכת.

הפרויקט נמצא בפיתוח במסגרת עבודת גמר במדעי המחשב. תכונות נוספות יתווספו בגרסאות הבאות.
